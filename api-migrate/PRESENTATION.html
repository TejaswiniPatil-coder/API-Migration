❓ The Problem

  • APIs evolve — methods get renamed, arguments change types
  • Parameters get reordered, methods become properties
  • Manual migration is tedious and error-prone
  • Simple find-and-replace cannot handle complex changes

Example: What needs to change?

# Old (deprecated)                    # New (target)
client.old_connect('host', '8080')  → client.connect('host', 8080)
auth.login('admin', 'secret')       → auth.authenticate({...})
token = auth.get_token()            → token = auth.token

💡 Our Solution

Use compiler techniques — not regex — to migrate APIs automatically

✅ What We Do

  • Parse code into AST
  • Build symbol tables
  • Semantic type checking
  • AST-based rewriting
  • 5-stage validation

❌ What We Don't Do

  • No regex replacement
  • No string matching
  • No blind AI generation
  • No manual intervention

🏗️ System Architecture

SOURCE CODE ↓ AST PARSER → Parse into Abstract Syntax Tree ↓ API DETECTOR → Find deprecated API calls ↓ SYMBOL ANALYZER → Build symbol table (variable → class) ↓ SEMANTIC ANALYZER → Type checking, argument validation ↓ MIGRATION PLANNER → Create transformation plans ↓ AST TRANSFORMER → Rewrite AST nodes (NodeTransformer) ↓ CODE GENERATOR → Generate new code + diff ↓ VALIDATION PIPELINE → 5 validators → PASS / FAIL

🔧 6 Transformation Types

#TypeExample
1Simple Renameclose_connection() → close()

3Rename + New Paramexecute_query(sql) → execute(query, params=None)
4Arg Reordersend_request(url,method,data) → request(method,url,body)
